# BibzCode AI

Built-in agent integration for BibzCode IDE.

- Configure eight providers through the Providers view.
- Store API keys with the operating-system credential service.
- Select and test models without putting credentials in the workspace.
- Create, resume, rename, export, and delete local sessions.
- Run the canonical BibzCode agent in an integrated sidebar scoped to a trusted
  multi-root workspace folder.
- Send the current editor selection to a new agent session.

Use **BibzCode: Set Up Managed Runtime** before the first agent launch. Core and full
runtime profiles are installed from hash-locked requirements.
