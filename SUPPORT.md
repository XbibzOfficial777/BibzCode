# BibzCode Support

Before requesting help:

1. Read `README.md`, the release notes, and relevant command help.
2. Confirm the issue still occurs on the latest release.
3. Search existing issues and pull requests.
4. Remove credentials and personal data from every log and screenshot.

Use the GitHub issue forms for reproducible bugs, feature proposals, and usage
questions. Support is best-effort; response times are not guaranteed.

Do **not** use a public support issue for vulnerabilities, compromised accounts,
production credentials, private user conversations, service-account data, or database
exports. Follow `SECURITY.md` for vulnerabilities and rotate compromised credentials
through the relevant provider.

Include operating system, Python version, BibzCode version, install mode, provider,
minimal reproduction steps, expected behavior, and sanitized error output. Avoid full
configuration files because they commonly contain secrets.
