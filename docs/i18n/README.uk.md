## Огляд

BibzCode — термінальний ШІ-агент із підтримкою кількох провайдерів, контрольованим виконанням інструментів, збереженням сесій, MCP, засобами для документів, автоматизацією браузера та додатковими конекторами Telegram/Discord.

## Вимоги

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Встановлення

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Типово інсталятор використовує рекомендоване кероване віртуальне середовище.

## Запуск

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
