## Przegląd

BibzCode to terminalowy agent AI obsługujący wielu dostawców, z kontrolowanym uruchamianiem narzędzi, trwałymi sesjami, MCP, narzędziami dokumentowymi, automatyzacją przeglądarki i opcjonalnymi łącznikami Telegram/Discord.

## Wymagania

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalacja

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Instalator domyślnie korzysta z zalecanego zarządzanego środowiska wirtualnego.

## Uruchomienie

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
