## Översikt

BibzCode är en terminalbaserad AI-agent för flera leverantörer med kontrollerad verktygskörning, beständiga sessioner, MCP, dokumentverktyg, webbläsarautomatisering och valfria Telegram/Discord-anslutningar.

## Krav

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installation

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Installationsprogrammet använder som standard den rekommenderade hanterade virtuella miljön.

## Start

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
