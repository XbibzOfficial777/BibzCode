## Pangkalahatang-ideya

Ang BibzCode ay multi-provider terminal AI agent na may kontroladong pagpapatakbo ng tools, session persistence, MCP, document utilities, browser automation, at opsyonal na Telegram/Discord connectors.

## Mga kinakailangan

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Pag-install

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Ginagamit ng installer ang inirerekomendang managed virtual environment bilang default.

## Pagsisimula

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
