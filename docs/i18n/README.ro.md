## Prezentare generală

BibzCode este un agent AI pentru terminal cu mai mulți furnizori, executare controlată a instrumentelor, sesiuni persistente, MCP, utilitare pentru documente, automatizarea browserului și conectori Telegram/Discord opționali.

## Cerințe

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalare

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Programul de instalare folosește implicit mediul virtual gestionat recomandat.

## Pornire

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
