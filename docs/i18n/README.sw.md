## Muhtasari

BibzCode ni wakala wa AI wa terminali unaotumia watoa huduma wengi, wenye utekelezaji wa zana unaodhibitiwa, uhifadhi wa vipindi, MCP, zana za nyaraka, uendeshaji wa kivinjari na viunganishi vya hiari vya Telegram/Discord.

## Mahitaji

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Usakinishaji

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Kisakinishi hutumia mazingira pepe yanayosimamiwa na kupendekezwa kwa chaguo-msingi.

## Anza

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
