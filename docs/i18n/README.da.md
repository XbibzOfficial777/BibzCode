## Oversigt

BibzCode er en terminalbaseret AI-agent med flere udbydere, kontrolleret værktøjsudførelse, vedvarende sessioner, MCP, dokumentværktøjer, browserautomatisering og valgfrie Telegram/Discord-forbindelser.

## Krav

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installation

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Installationsprogrammet bruger som standard det anbefalede administrerede virtuelle miljø.

## Start

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
