## পরিচিতি

BibzCode একটি বহু-প্রদানকারী টার্মিনাল AI এজেন্ট, যাতে নিয়ন্ত্রিত টুল চালনা, সেশন সংরক্ষণ, MCP, ডকুমেন্ট টুল, ব্রাউজার অটোমেশন এবং ঐচ্ছিক Telegram/Discord সংযোগ রয়েছে।

## প্রয়োজনীয়তা

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## ইনস্টল

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

ইনস্টলার ডিফল্টভাবে প্রস্তাবিত managed virtual environment ব্যবহার করে।

## চালু করুন

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
