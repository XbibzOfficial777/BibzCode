## Überblick

BibzCode ist ein terminalbasierter KI-Agent für mehrere Anbieter mit kontrollierter Werkzeugausführung, dauerhaften Sitzungen, MCP, Dokumentwerkzeugen, Browserautomatisierung und optionalen Telegram/Discord-Konnektoren.

## Voraussetzungen

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installation

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Das Installationsprogramm verwendet standardmäßig die empfohlene verwaltete virtuelle Umgebung.

## Start

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
