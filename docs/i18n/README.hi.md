## परिचय

BibzCode एक बहु-प्रदाता टर्मिनल AI एजेंट है जिसमें नियंत्रित टूल निष्पादन, सत्र संरक्षण, MCP, दस्तावेज़ टूल, ब्राउज़र स्वचालन और वैकल्पिक Telegram/Discord कनेक्टर हैं।

## आवश्यकताएँ

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## इंस्टॉल करें

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

इंस्टॉलर डिफ़ॉल्ट रूप से अनुशंसित managed virtual environment का उपयोग करता है।

## शुरू करें

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## सुरक्षा और योगदान

API key, password या token साझा न करें। सुरक्षा कमज़ोरी की निजी रूप से रिपोर्ट करें और pull request से पहले योगदान गाइड पढ़ें।
