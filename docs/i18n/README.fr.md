## Présentation

BibzCode est un agent IA multiprestataire pour terminal avec exécution contrôlée des outils, persistance des sessions, MCP, outils documentaires, automatisation du navigateur et connecteurs Telegram/Discord facultatifs.

## Prérequis

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installation

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

L’installateur utilise par défaut l’environnement virtuel géré recommandé.

## Démarrage

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
