## Apžvalga

BibzCode yra kelių teikėjų terminalo DI agentas su valdoma įrankių vykdymo sistema, išsaugomomis sesijomis, MCP, dokumentų įrankiais, naršyklės automatizavimu ir pasirenkamomis Telegram/Discord jungtimis.

## Reikalavimai

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Diegimas

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Diegimo programa pagal numatymą naudoja rekomenduojamą valdomą virtualią aplinką.

## Paleidimas

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
