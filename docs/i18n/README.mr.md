> हा संक्षिप्त मराठी अनुवाद आहे. इंग्रजी README हा अधिकृत आणि सर्वात अद्ययावत दस्तऐवज आहे.

## आढावा

BibzCode हा नियंत्रित साधन अंमलबजावणी, सत्र जतन, MCP, दस्तऐवज साधने, ब्राउझर ऑटोमेशन आणि पर्यायी Telegram/Discord कनेक्टर असलेला बहु-प्रदाता टर्मिनल AI एजंट आहे.

## आवश्यकता

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## स्थापना

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

इंस्टॉलर डीफॉल्टनुसार शिफारस केलेले managed virtual environment वापरतो.

## सुरू करा

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## सुरक्षा आणि योगदान

API key, password किंवा token शेअर करू नका. असुरक्षा खाजगीरित्या कळवा आणि pull request करण्यापूर्वी योगदान मार्गदर्शक वाचा.
