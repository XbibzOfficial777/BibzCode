## معرفی

BibzCode یک عامل هوش مصنوعی ترمینالی با پشتیبانی از چند ارائه‌دهنده، اجرای کنترل‌شدهٔ ابزارها، نگهداری نشست‌ها، MCP، ابزارهای سند، خودکارسازی مرورگر و اتصال‌های اختیاری Telegram/Discord است.

## نیازمندی‌ها

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## نصب

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

نصب‌کننده به‌طور پیش‌فرض از محیط مجازی مدیریت‌شده و پیشنهادی استفاده می‌کند.

## اجرا

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

کلید API، گذرواژه یا توکن را به اشتراک نگذارید. آسیب‌پذیری‌ها را خصوصی گزارش کنید و پیش از pull request راهنمای مشارکت را بخوانید.
