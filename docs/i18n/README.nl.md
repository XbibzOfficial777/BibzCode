## Overzicht

BibzCode is een terminal-AI-agent voor meerdere providers met gecontroleerde tooluitvoering, blijvende sessies, MCP, documenthulpmiddelen, browserautomatisering en optionele Telegram/Discord-connectors.

## Vereisten

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installatie

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Het installatieprogramma gebruikt standaard de aanbevolen beheerde virtuele omgeving.

## Starten

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
