## Oversikt

BibzCode er en terminalbasert AI-agent for flere leverandører med kontrollert verktøykjøring, varige økter, MCP, dokumentverktøy, nettleserautomatisering og valgfrie Telegram/Discord-koblinger.

## Krav

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installasjon

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Installasjonsprogrammet bruker som standard det anbefalte administrerte virtuelle miljøet.

## Start

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
