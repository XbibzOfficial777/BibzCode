## جائزہ

BibzCode ایک متعدد فراہم کنندگان والا ٹرمینل AI ایجنٹ ہے جس میں کنٹرول شدہ ٹول چلانا، سیشن محفوظ رکھنا، MCP، دستاویزی اوزار، براؤزر آٹومیشن اور اختیاری Telegram/Discord کنیکٹر شامل ہیں۔

## ضروریات

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## تنصیب

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

انسٹالر بطور ڈیفالٹ تجویز کردہ managed virtual environment استعمال کرتا ہے۔

## شروع کریں

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
