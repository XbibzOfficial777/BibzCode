## Преглед

BibzCode је терминалски AI агент за више добављача са контролисаним извршавањем алата, трајним сесијама, MCP подршком, алатима за документе, аутоматизацијом прегледача и опционим Telegram/Discord конекторима.

## Захтеви

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Инсталација

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Инсталатер подразумевано користи препоручено управљано виртуелно окружење.

## Покретање

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## Безбедност и допринос

Не делите API кључеве, лозинке или токене. Рањивости пријавите приватно и прочитајте водич за допринос пре pull request-а.
