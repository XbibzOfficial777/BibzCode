## Преглед

BibzCode е терминален AI агент с множество доставчици, контролирано изпълнение на инструменти, запазване на сесии, MCP, инструменти за документи, автоматизация на браузър и допълнителни Telegram/Discord конектори.

## Изисквания

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Инсталиране

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Инсталаторът използва препоръчителна управлявана виртуална среда по подразбиране.

## Стартиране

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
