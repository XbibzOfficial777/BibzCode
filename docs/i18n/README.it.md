## Panoramica

BibzCode è un agente IA multi-provider per terminale con esecuzione controllata degli strumenti, persistenza delle sessioni, MCP, utilità per documenti, automazione del browser e connettori Telegram/Discord opzionali.

## Requisiti

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Installazione

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Il programma di installazione usa per impostazione predefinita l’ambiente virtuale gestito consigliato.

## Avvio

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
