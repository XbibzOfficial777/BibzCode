## 개요

BibzCode는 제어된 도구 실행, 세션 유지, MCP, 문서 도구, 브라우저 자동화 및 선택적 Telegram/Discord 커넥터를 제공하는 다중 공급자 터미널 AI 에이전트입니다.

## 요구 사항

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## 설치

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

설치 프로그램은 권장되는 관리형 가상 환경을 기본으로 사용합니다.

## 시작

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
