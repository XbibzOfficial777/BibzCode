## Áttekintés

A BibzCode több szolgáltatót támogató terminálos AI-ügynök, ellenőrzött eszközfuttatással, tartós munkamenetekkel, MCP-vel, dokumentumeszközökkel, böngészőautomatizálással és választható Telegram/Discord csatlakozókkal.

## Követelmények

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Telepítés

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

A telepítő alapértelmezetten az ajánlott felügyelt virtuális környezetet használja.

## Indítás

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
