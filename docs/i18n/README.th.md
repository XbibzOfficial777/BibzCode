## ภาพรวม

BibzCode เป็นเอเจนต์ AI บนเทอร์มินัลที่รองรับหลายผู้ให้บริการ มีการควบคุมการเรียกใช้เครื่องมือ การเก็บเซสชัน MCP เครื่องมือเอกสาร ระบบอัตโนมัติของเบราว์เซอร์ และตัวเชื่อมต่อ Telegram/Discord แบบเลือกใช้

## ข้อกำหนด

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## การติดตั้ง

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

ตัวติดตั้งใช้สภาพแวดล้อมเสมือนแบบจัดการที่แนะนำเป็นค่าเริ่มต้น

## เริ่มใช้งาน

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## ความปลอดภัยและการมีส่วนร่วม

อย่าเผยแพร่ API key รหัสผ่าน หรือ token โปรดรายงานช่องโหว่เป็นการส่วนตัวและอ่านคู่มือการมีส่วนร่วมก่อนส่ง pull request
