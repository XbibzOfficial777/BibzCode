## అవలోకనం

BibzCode అనేది నియంత్రిత సాధన అమలు, సెషన్ నిల్వ, MCP, డాక్యుమెంట్ సాధనాలు, బ్రౌజర్ ఆటోమేషన్ మరియు ఐచ్ఛిక Telegram/Discord కనెక్టర్లతో కూడిన బహుళ-ప్రొవైడర్ టెర్మినల్ AI ఏజెంట్.

## అవసరాలు

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## ఇన్‌స్టాలేషన్

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

ఇన్‌స్టాలర్ డిఫాల్ట్‌గా సిఫార్సు చేసిన managed virtual environment‌ను ఉపయోగిస్తుంది.

## ప్రారంభించండి

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
