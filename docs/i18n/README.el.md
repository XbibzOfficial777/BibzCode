## Επισκόπηση

Το BibzCode είναι ένας τερματικός πράκτορας AI πολλαπλών παρόχων με ελεγχόμενη εκτέλεση εργαλείων, διατήρηση συνεδριών, MCP, εργαλεία εγγράφων, αυτοματοποίηση προγράμματος περιήγησης και προαιρετικές συνδέσεις Telegram/Discord.

## Απαιτήσεις

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Εγκατάσταση

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Το πρόγραμμα εγκατάστασης χρησιμοποιεί από προεπιλογή το προτεινόμενο διαχειριζόμενο εικονικό περιβάλλον.

## Εκκίνηση

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
