## Descripció

BibzCode és un agent d’IA multiproveïdor per al terminal amb execució controlada d’eines, persistència de sessions, MCP, utilitats de documents, automatització del navegador i connectors opcionals de Telegram/Discord.

## Requisits

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instal·lació

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

L’instal·lador utilitza per defecte un entorn virtual gestionat, l’opció recomanada.

## Inici

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
