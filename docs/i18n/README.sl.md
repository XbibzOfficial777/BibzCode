## Pregled

BibzCode je terminalski agent umetne inteligence za več ponudnikov z nadzorovanim izvajanjem orodij, trajnimi sejami, MCP, dokumentnimi orodji, avtomatizacijo brskalnika in izbirnimi povezovalniki Telegram/Discord.

## Zahteve

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Namestitev

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Namestitveni program privzeto uporabi priporočeno upravljano navidezno okolje.

## Zagon

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
