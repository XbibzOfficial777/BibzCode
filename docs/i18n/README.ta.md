## மேலோட்டம்

BibzCode என்பது கட்டுப்படுத்தப்பட்ட கருவி இயக்கம், அமர்வு சேமிப்பு, MCP, ஆவணக் கருவிகள், உலாவி தானியக்கம் மற்றும் விருப்பமான Telegram/Discord இணைப்புகளுடன் கூடிய பல வழங்குநர் முனைய AI முகவர்.

## தேவைகள்

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## நிறுவல்

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

நிறுவி இயல்பாக பரிந்துரைக்கப்பட்ட managed virtual environment-ஐ பயன்படுத்துகிறது.

## தொடங்குதல்

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## பாதுகாப்பு மற்றும் பங்களிப்பு

API key, password அல்லது token-ஐ பகிர வேண்டாம். பாதிப்புகளை தனிப்பட்ட முறையில் தெரிவித்து, pull request முன் பங்களிப்பு வழிகாட்டியைப் படிக்கவும்.
