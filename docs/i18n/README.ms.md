## Gambaran keseluruhan

BibzCode ialah ejen AI terminal berbilang penyedia dengan pelaksanaan alat terkawal, pengekalan sesi, MCP, utiliti dokumen, automasi pelayar dan penyambung Telegram/Discord pilihan.

## Keperluan

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Pemasangan

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Pemasang menggunakan persekitaran maya terurus yang disyorkan secara lalai.

## Mula

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.

## Keselamatan dan sumbangan

Jangan kongsi kunci API, kata laluan atau token. Laporkan kerentanan secara peribadi dan baca panduan sumbangan sebelum membuka pull request.
