## Prehľad

BibzCode je terminálový AI agent pre viacerých poskytovateľov s riadeným spúšťaním nástrojov, trvalými reláciami, MCP, nástrojmi pre dokumenty, automatizáciou prehliadača a voliteľnými konektormi Telegram/Discord.

## Požiadavky

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Inštalácia

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Inštalátor predvolene používa odporúčané spravované virtuálne prostredie.

## Spustenie

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
