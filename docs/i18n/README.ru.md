## Обзор

BibzCode — терминальный ИИ-агент с поддержкой нескольких провайдеров, контролируемым запуском инструментов, сохранением сессий, MCP, средствами работы с документами, автоматизацией браузера и дополнительными коннекторами Telegram/Discord.

## Требования

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Установка

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

По умолчанию установщик использует рекомендуемое управляемое виртуальное окружение.

## Запуск

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
