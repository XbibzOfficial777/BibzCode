## Yleiskuva

BibzCode on usean palveluntarjoajan terminaali-AI-agentti, jossa on hallittu työkalujen suoritus, pysyvät istunnot, MCP, asiakirjatyökalut, selainautomaatio ja valinnaiset Telegram/Discord-yhdistimet.

## Vaatimukset

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Asennus

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Asennusohjelma käyttää oletuksena suositeltua hallittua virtuaaliympäristöä.

## Käynnistys

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
