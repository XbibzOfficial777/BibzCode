## Genel bakış

BibzCode; denetimli araç çalıştırma, kalıcı oturumlar, MCP, belge araçları, tarayıcı otomasyonu ve isteğe bağlı Telegram/Discord bağlayıcıları sunan çok sağlayıcılı bir terminal yapay zekâ aracısıdır.

## Gereksinimler

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Kurulum

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Kurucu varsayılan olarak önerilen yönetilen sanal ortamı kullanır.

## Başlatma

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
