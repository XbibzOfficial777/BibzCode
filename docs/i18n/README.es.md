## Descripción general

BibzCode es un agente de IA multiproveedor para terminal con ejecución controlada de herramientas, persistencia de sesiones, MCP, utilidades de documentos, automatización del navegador y conectores opcionales de Telegram/Discord.

## Requisitos

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalación

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

El instalador utiliza de forma predeterminada el entorno virtual administrado recomendado.

## Inicio

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
