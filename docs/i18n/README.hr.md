## Pregled

BibzCode je terminalski AI agent za više pružatelja s kontroliranim izvršavanjem alata, trajnim sesijama, MCP podrškom, alatima za dokumente, automatizacijom preglednika i neobaveznim Telegram/Discord poveznicima.

## Preduvjeti

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalacija

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Instalacijski program prema zadanim postavkama koristi preporučeno upravljano virtualno okruženje.

## Pokretanje

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
