## Pārskats

BibzCode ir vairāku pakalpojumu sniedzēju termināļa MI aģents ar kontrolētu rīku izpildi, sesiju saglabāšanu, MCP, dokumentu rīkiem, pārlūka automatizāciju un izvēles Telegram/Discord savienotājiem.

## Prasības

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalēšana

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Instalētājs pēc noklusējuma izmanto ieteicamo pārvaldīto virtuālo vidi.

## Palaišana

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
