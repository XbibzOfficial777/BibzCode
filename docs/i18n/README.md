# BibzCode documentation languages

BibzCode documentation is available in **48 languages**. English is the canonical,
default README. Bahasa Indonesia receives extended first-class coverage. Other
translations provide an essential quick start and link back to the complete English
documentation.

If translated text conflicts with code, security policy, or the English README, the
English version controls until the translation is corrected.

## Help maintain a translation

Read [`TRANSLATING.md`](TRANSLATING.md) before submitting translation changes. Pull
requests target `nightly` and should ideally be reviewed by a fluent speaker. Commands,
URLs, environment variables, code identifiers, and security requirements must not be
translated or weakened.
