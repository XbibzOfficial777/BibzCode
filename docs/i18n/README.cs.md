## Přehled

BibzCode je terminálový AI agent pro více poskytovatelů s řízeným spouštěním nástrojů, ukládáním relací, MCP, nástroji pro dokumenty, automatizací prohlížeče a volitelnými konektory Telegram/Discord.

## Požadavky

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalace

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Instalátor ve výchozím nastavení používá doporučené spravované virtuální prostředí.

## Spuštění

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
