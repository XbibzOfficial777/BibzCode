## Tổng quan

BibzCode là tác nhân AI đa nhà cung cấp chạy trong terminal, có cơ chế thực thi công cụ được kiểm soát, lưu phiên, MCP, tiện ích tài liệu, tự động hóa trình duyệt và bộ kết nối Telegram/Discord tùy chọn.

## Yêu cầu

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Cài đặt

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Trình cài đặt mặc định sử dụng môi trường ảo được quản lý và khuyến nghị.

## Khởi động

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
