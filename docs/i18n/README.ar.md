## نبذة

BibzCode وكيل ذكاء اصطناعي متعدد المزوّدين يعمل في الطرفية، مع تنفيذ أدوات مضبوط، وحفظ الجلسات، ودعم MCP، وأدوات المستندات وأتمتة المتصفح وموصلات Telegram وDiscord الاختيارية.

## المتطلبات

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## التثبيت

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

يستخدم المثبّت افتراضياً بيئة افتراضية مُدارة، وهي الخيار الموصى به.

## التشغيل

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
