## סקירה

BibzCode הוא סוכן AI למסוף התומך במספר ספקים, עם הפעלה מבוקרת של כלים, שמירת הפעלות, MCP, כלי מסמכים, אוטומציית דפדפן ומחברי Telegram/Discord אופציונליים.

## דרישות

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## התקנה

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

תוכנית ההתקנה משתמשת כברירת מחדל בסביבה וירטואלית מנוהלת ומומלצת.

## הפעלה

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
