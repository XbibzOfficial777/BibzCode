> આ સંક્ષિપ્ત ગુજરાતી અનુવાદ છે. અંગ્રેજી README મુખ્ય અને સૌથી અદ્યતન દસ્તાવેજ છે.

## પરિચય

BibzCode નિયંત્રિત ટૂલ અમલ, સેશન સંગ્રહ, MCP, દસ્તાવેજ સાધનો, બ્રાઉઝર ઓટોમેશન અને વૈકલ્પિક Telegram/Discord કનેક્ટર્સ ધરાવતો મલ્ટી-પ્રોવાઇડર ટર્મિનલ AI એજન્ટ છે.

## જરૂરિયાતો

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## ઇન્સ્ટોલેશન

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

ઇન્સ્ટોલર મૂળભૂત રીતે ભલામણ કરેલ managed virtual environment વાપરે છે.

## શરૂઆત

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
