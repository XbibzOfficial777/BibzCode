## Visão geral

BibzCode é um agente de IA multiprovedor para terminal com execução controlada de ferramentas, persistência de sessões, MCP, utilitários de documentos, automação de navegador e conectores opcionais do Telegram/Discord.

## Requisitos

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Instalação

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

O instalador usa por padrão o ambiente virtual gerenciado recomendado.

## Iniciar

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
