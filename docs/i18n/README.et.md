## Ülevaade

BibzCode on mitme teenusepakkujaga terminali tehisintellektiagent, millel on kontrollitud tööriistade käivitamine, püsivad seansid, MCP, dokumenditööriistad, brauseri automatiseerimine ja valikulised Telegrami/Discordi ühendused.

## Nõuded

- Python **3.10+**
- Linux, macOS, or Termux
- A Firebase account for CLI access
- An API key for at least one supported LLM provider

## Paigaldamine

```bash
curl -fsSL https://bibzcode.bibzflow.workers.dev/install.sh | bash
```

Paigaldaja kasutab vaikimisi soovitatud hallatud virtuaalkeskkonda.

## Käivitamine

```bash
bzcli
```

`bzcli` is the canonical command. `dscli` remains only as a temporary compatibility alias.
